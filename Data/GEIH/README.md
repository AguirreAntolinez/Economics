# GEIH

This folder contains data from the Gran Encuesta Integrada de Hogares (GEIH). 
GIEH is a survey conducted by DANE. To see the original data and variable dictionary, visit the official website https://microdatos.dane.gov.co/index.php/catalog/MERCLAB-Microdatos.

The owner of this repository has no relationship with DANE and isn't the responsible for the statistical quality of this dataset.
